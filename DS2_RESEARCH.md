# You Are Empty: формат геометрии уровней DS2

## Область исследования

Разобран `DS2GeometryFile_1`, версия `0.8`: все 17 файлов из `gameres/maps/map00`…`map16`, суммарно 697832959 байт и 65606 описаний мешей. Исследованы геометрия, оба UV-набора, материалы, атласы освещения, матрицы объектов, отдельные потоки цвета инстансов и служебные секции.

Коллизии `.ds2cm`/`.ds2cm2` и навигация `.ds2aim` не исследовались. Подробный разбор октодерева приведён в [VISTREE_RESEARCH.md](VISTREE_RESEARCH.md).

## Источники доказательств

Структура восстановлена сопоставлением реальных файлов с дизассемблированием x86 PE. Названия полей исследовательские, кроме подтверждённых потребителями и именами материалов. Адреса — VA при preferred base `0x10000000`.

Бинарник: `ds2render.dll`, SHA-256 `216c22891726e624787918396112127f157de0255e70994be01fe509a3624c78`.

| Назначение | VA |
|---|---|
| Загрузчик геометрии CScene | `0x100565F0` |
| Чтение байтов / String | `0x100546E0` / `0x10056010` |
| Секция / запись меша | `0x100561C0` / `0x10058850` |
| Секция / запись буфера | `0x100562E0` / `0x1005AB80` |
| Список лайтмап | `0x10056050` |

| Секция / запись источника света | `0x10056400` / `0x10057540` |

## Базовые типы и секции

Little-endian, плотная упаковка без padding. `f32` — IEEE 754. `String = u16 byte_length + byte[byte_length]`, без NUL. Кодировка непомеченных строк не установлена.

```text
String "DS2GeometryFile_1"
String "0.8"
repeat to EOF:
    String "DS2Chunk_begin"
    String chunk_name
    payload
    String "DS2Chunk_end"
```

У секции **нет длины в байтах**. Поиск маркера внутри бинарного payload не позволяет корректно пропустить неизвестную секцию. В файлах встречаются `meshes`, `buffers`, `lightmaps`, `vistree`, необязательная `lights`, `models`.

Оригинальный загрузчик проверяет версию численно как 0.8, а завершающий маркер потребляет внешним циклом без отдельной проверки.

## Меши

`meshes = u32 count + Mesh[count]`. Начало записи:

```text
u8 instanced
String material
String diffuse
String bump
String luminosity
String reflection
String specular
```

Далее смещения относительно конца шестой строки (`S`):

| Смещение | Тип | Назначение |
|---|---|---|
| `S+0` | Float3 | AABB min |
| `S+12` | Float3 | AABB max |
| `S+24` | Float3 | Центр сферы |
| `S+36` | f32 | Радиус сферы |
| `S+40` | 156 байт | Дополнительный bounds-блок: 12+12+36+96 байт |
| `S+196` | u8 | Флаг в памяти `+0x114`, точная семантика не установлена |
| `S+197` | Float3 | Вектор в памяти `+0x118`, точная семантика не установлена |
| `S+209` | u32 | Индекс лайтмапы, `FFFFFFFF` в корпусе означает отсутствие |
| `S+213` | u32 | Число примитивов |
| `S+217` | u32 | Число вершин меша |
| `S+221` | u32 | Поле памяти `+0xD8`, точная семантика не установлена |
| `S+225` | u32 | Число индексов triangle list |
| `S+229` | u32 | ID индексного буфера list |
| `S+233` | u32 | Начальный индекс list, в элементах |
| `S+237` | u32 | Число индексов triangle strip |
| `S+241` | u32 | ID индексного буфера strip |
| `S+245` | u32 | Начальный индекс strip, в элементах |
| `S+249` | u32 | ID буфера вершин |
| `S+253` | u32 | База вершин в буфере |

Фиксированный хвост — 257 байт. В движке индекс лайтмапы и три следующих поля сохраняются младшими 16 битами; в файле эти поля занимают по 32 бита.

List и strip — **два независимых диапазона**, а не переключатель топологии или LOD. `0x10057F80` рисует оба ненулевых диапазона. ID/начало пустого диапазона могут быть `FFFFFFFF`; их нельзя безусловно разыменовывать. Индекс обращается к `VB[vertex_start + index]`: у обычных world-мешей база часто нулевая, а индексы охватывают общий VB, не только `vertex_count` данного меша.

Если `instanced != 0`, после `S+257` следуют ещё 80 байт:

```text
u32 color_buffer_id
u32 color_vertex_start
f32 matrix[16]
u32 model_group_reference
u32 model_instance_reference
```

Это отдельный поток запечённого RGBA для экземпляра, не дополнительная геометрия. Матрица хранится row-major, translation в элементах 3, 7, 11. Перед вызовом `OPENGL32!glMultMatrixf` матрица транспонируется.

Каждая такая запись рисуется **один раз со своей матрицей**. Повторное размножение по секции `models` создаёт дубликаты. Ссылки на группы и экземпляры полезны как метаданные, но не годятся для строгой проверки связи: в корпусе есть расхождения матриц и выходы этих advisory-ссылок за число экземпляров. Авторитетна матрица самого меша.

## Общие буферы

`buffers = u32 count + Buffer[count]`. Счётчик общий для VB, IB и отдельных цветовых буферов.

```text
u32 flags
u32 count
if flags & 1:
    u32 indices[count]
else:
    optional attribute arrays in the order below
```

| Бит | Массив | Байт на элемент |
|---|---|---|
| `0x02` | Float3 positions | 12 |
| `0x08` | Float2 albedo UV | 8 |
| `0x10` | Float2 lightmap UV | 8 |
| `0x20` | u32 RGBA[4] | 16 |
| `0x04` | Float3 normals | 12 |
| `0x40` | Float3 tangents | 12 |
| `0x80` | Float3 binormals | 12 |

Это SoA, **не interleaved**. Порядок не совпадает с сортировкой битов. `0x1A` означает позиции + два UV-набора. Цвет на диске — четыре u32 на вершину; движок использует младший байт каждого канала и получает RGBA8. Индексы на диске u32, хотя движок преобразует их в u16.

Некоторые нормали и тангенты поставляемых файлов содержат NaN. В UV встречаются очень большие **конечные** значения.

## Лайтмапы и альбедо

`lightmaps = u32 count + String[count]`. Порядок списка задаёт нулевые индексы атласов. Например, `lastzlo\\lastzlo_lm_0` указывает на соседний `lastzlo_lm_0.tga`. Имена нельзя синтезировать из номера материала или числа лежащих рядом изображений.

Всего рядом с картами 35 TGA, но `.ds2` ссылаются только на 32. Неиспользуемые этим набором геометрии: `map05/kolhoz_lm_2.tga`, `map07/lastlevel_lm_3.tga`, `map09/meat_lm_1.tga`.

Ссылки diffuse часто содержат старые пути `D:\\quake`, `Z:\\gameres` или UNC разработчиков. Все 60 встреченных имён материалов имеют декларации в `gameres/materials/*.mat`.

DDS сохраняет исходную V. TGA имеет нижнее начало координат, поэтому при использовании общей UV-системы требуется преобразование `1-V`. Инверсия независима для альбедо и лайтмапы. Все 35 соседних lightmap TGA имеют descriptor 0 (bottom-origin).

## Статическое освещение и материалы

Обычные fixed-function пути подтверждены дизассемблированием, а не только Cg-шейдерами:

- LM: `RGB = 2 * albedo * lightmap`, дополнительно умножение на vertex RGB при `use_vertex_colors`.
- VX: `RGB = albedo * vertex RGB * (2 if overbright else 1)`; `overbright` по умолчанию включён.
- Self-illumination: `RGB = albedo * constant color`, без усиления; `def_selfilum_50` даёт `0.5 * albedo`.
- Усиление 2 относится только к RGB, не alpha.

LM использует texenv mode 7 → `0x10044FA2`, `GL_COMBINE/MODULATE`, `GL_RGB_SCALE=2` в `0x1004500E`. VX mode 9 → `0x10045120`, TEXTURE × PRIMARY_COLOR с усилением 2. Self-illumination выбирает mode 0; `0x10044260` задаёт белый RGBA, если нет явного color3.

Встречаются runtime-поля `blend`, `alphatest { greater threshold }`, `depth_write`, `depth_test`, `depth_offset`, `cull_face`, `sort_value`, `color3`, `diffuse_texture`, `clampmap`, `self_illumination`, `use_vertex_colors`, `overbright`. `material_type opaque` не запрещает явный blend; `ds2compiler transparent` сам по себе **не** включает runtime-прозрачность. Наличие alpha в DDS также не включает blending автоматически. `fallback_material` — аппаратный fallback, не наследование.

В `.mat` встречаются вложенные блоки, `//`, `/* … */` и незакрытый block-comment до EOF в `ds2_man.mat`; закомментированная декларация не должна переопределять рабочую. Подстановки `$diffuse$`, `$white$`, `$black$` обрабатываются отдельно от имён файлов. У материала без diffuse-слота не подставляется произвольно diffuse из меша.

## Служебные секции

Все секции начинаются с u32 count:

- `vistree`: разреженное октодерево. Запись содержит Float3 min/max, **f32 радиус сферы** (`sphere_radius`), Float3 центр (`sphere_center`) и u8 leaf; лист — список индексов мешей с пересекающимися AABB, внутренний узел — восемь child IDs с `FFFFFFFF` для отсутствующих детей. Полная структура, обработка индексов движком и отдельная окклюзия описаны в [VISTREE_RESEARCH.md](VISTREE_RESEARCH.md); это не PVS.
- `lights`: 72 байта на запись; типы, основные поля и неустановленные параметры описаны ниже.
- `models`: String name, Float3 min/max, u32 instanceCount; экземпляр = Matrix4 + Float3 min/max, 88 байт на диске. Размер структуры в памяти 100 байт переносить на файл нельзя.

### Chunk `lights`

Формат записи: `u32 type + три Float3 + восемь 32-битных параметров`. Типы подтверждены передачей записи в OpenGL по `0x10044800`: `1` — point, `2` — directional, `3` — spot. Загрузчик `0x10057540` преобразует их во внутренние значения `1`, `0`, `2` соответственно.

| Смещение | Семантика и статус |
|---:|---|
| `+0x00` | `u32 type`: `1` point, `2` directional, `3` spot. |
| `+0x04` | Float3 position. |
| `+0x10` | Float3 direction; у point не используется. |
| `+0x1C` | Float3 diffuse color. |
| `+0x28` | Range: ограничивает AABB источника и расстояние при запросе освещения. |
| `+0x2C` | **Не установлено.** |
| `+0x30` | **Не установлено.** У всех point/spot проверенного корпуса значение совпадает с range, но это не раскрывает назначение поля. |
| `+0x34` | **Не установлено.** Потребитель не подтверждён; присваивать этому полю inner spot angle по одним значениям корпуса нельзя. |
| `+0x38` | Outer spot angle в градусах. OpenGL получает `GL_SPOT_CUTOFF = angle / 2`; запрос освещения принимает угол не больше `(angle + 1) / 2`. |
| `+0x3C` | **Не установлено.** |
| `+0x40` | Читается как bool; назначение **не установлено**. |
| `+0x44` | Читается как bool; назначение **не установлено**. |

Статус **«не установлено»** означает отсутствие подтверждённой семантики в исследованных путях, а не отсутствие потребителей в других частях движка. Cg-шейдеры, скриптовые интерфейсы и все остальные читатели записей не проверены исчерпывающе.

Directional lights попадают в отдельный глобальный список. Point и spot связываются с листьями `vistree` по AABB `position ± range` (`0x10056B80`, `0x10056F90`). Запрос `0x1004A660` проверяет `distance < range`, cone у spot и отсутствие перекрытия collision-ray. OpenGL-uploader `0x10044800` подтверждает position, direction, diffuse color и outer spot angle; остальные параметры этот путь не раскрывает.

В проверенных 17 картах 746 записей: 422 point, 323 spot и одна directional. Направления directional/spot нормализованы, range положительный.
