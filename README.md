# DS2 Research

Неофициальный инструментарий для исследования движка **DS2** и его форматов ресурсов. Основная цель проекта — **You Are Empty** от Digital Spray.

Инструменты технически поддерживают открытие всех моделей и карт **Instinct**, следующей игры студии: форматы моделей и уровней не изменились. Однако точно воспроизвести изображение Instinct проект не может: в этой игре используются HDR-освещение, normal mapping, bump mapping и другие технологии рендеринга, которые здесь не учитываются. Для **You Are Empty** viewer способен правильно отображать итоговые уровни и модели, поскольку игра использует значительно более простые модели освещения и рендеринга.

Проект полностью написан с помощью AI.

В состав входят:

- `ds2_view` — просмотр карт DS2 с материалами, лайтмапами, источниками света и группами моделей.
- `ds2md_view` — просмотр моделей DS2MD, воспроизведение анимации и экспорт в GLB.
- Python-пакет `ds2_research` — парсеры, проверка структуры и JSON-отчёты без сторонних зависимостей.
- [Исследования форматов](docs/README.md) — бинарные схемы, наблюдения по корпусу файлов и ссылки на адреса в игровых DLL.

Проект не содержит ресурсы игры и не запускает её код. Для просмотра карт и моделей нужна отдельно установленная копия игры.

## Поддерживаемые форматы

| Формат | Версии | Поддержка |
|---|---|---|
| DS2 | `DS2GeometryFile_1`, `0.8` | Парсер и Qt-viewer |
| DS2MD | Текстовый `0.5`; бинарные `0.6`, `0.9`, `1.0` | Парсер и Qt-viewer |
| `.ds2cm`, `.ds2cm2`, `.ds2aim` | — | Не исследованы |

Ограничения и неустановленные поля перечислены в документации соответствующего формата.

## Требования

Для нативных viewer:

- Windows с Visual Studio 2022 и MSVC x64 для готовых PowerShell-скриптов;
- Qt **6.11**, включая `Widgets`, `GuiPrivate` и `ShaderTools`;
- CMake **3.24+** и Ninja;
- компилятор с поддержкой C++20.

Для Python-инструментов — Python **3.10+**. Внешние Python-зависимости не нужны.

## Сборка Qt-viewer

Из корня репозитория в PowerShell:

```powershell
.\build.ps1
```

Скрипт использует Qt из `C:/Qt/6.11.0/msvc2022_64`, при необходимости активирует среду MSVC и собирает Release в `build/`. Пути и конфигурацию можно изменить:

```powershell
.\build.ps1 `
  -QtRoot 'D:/Qt/6.11.0/msvc2022_64' `
  -Configuration RelWithDebInfo `
  -BuildDirectory "$PWD/build-relwdeb"
```

Результат: `build/ds2_view.exe` и `build/ds2md_view.exe`. Qt DLL развёртываются рядом с исполняемыми файлами автоматически.

Для отдельного установочного каталога после сборки:

```powershell
.\install.ps1
```

По умолчанию файлы копируются в `install/`. Другой каталог задаётся через `-Prefix`.

## Использование viewer

Запуск с автоматическим поиском каталога `gameres` относительно открытого файла, текущего каталога или каталога программы:

```powershell
.\build\ds2_view.exe
.\build\ds2md_view.exe
```

Если ресурсы находятся в другом месте, передайте корень установки игры явно:

```powershell
.\build\ds2_view.exe --game-root 'D:/Games/You Are Empty'
.\build\ds2md_view.exe --game-root 'D:/Games/You Are Empty'
```

Файл можно открыть через **Ctrl+O**, перетащить в окно или передать первым позиционным аргументом:

```powershell
.\build\ds2_view.exe 'path/to/map.ds2'
.\build\ds2md_view.exe 'path/to/model.ds2md'
```

Имена в командах выше являются примерами путей; выберите существующий `.ds2` или `.ds2md` из своей установки.

### Параметры командной строки

| Параметр | Программа | Назначение |
|---|---|---|
| `--game-root <directory>` | Оба | Каталог установки, содержащий `gameres` |
| `--screenshot <file>` | Оба | Сохранить кадр и завершить работу; для модели файл обязателен |
| `--debug-rhi` | Оба | Включить слой диагностики графического API |
| `--mode <mode>` | `ds2_view` | `combined`, `albedo`, `lightmap`, `colors` или `meshes` |
| `--export-glb <file>` | `ds2md_view` | Экспортировать модель, все анимационные клипы и встроить текстуры, затем завершить работу |

Пример экспорта:

```powershell
.\build\ds2md_view.exe 'path/to/model.ds2md' --export-glb 'model.glb'
```

`--export-glb` нельзя совмещать с `--screenshot`.

### Управление

Общие действия: **Ctrl+O** — открыть файл, **Esc** — закрыть окно. Полный список также доступен кнопкой **Controls** в программе.

| Программа | Действия |
|---|---|
| `ds2_view` | ЛКМ — вращение; СКМ — панорама; ПКМ — обзор в режиме полёта; колесо — масштаб/скорость; **F** — полёт/орбита; **WASD**, **Q/E** — движение; **Shift** — ускорение; **Home** — вместить карту или выделение; **1–5** — режимы отображения; **G** — каркас; **M** — модели; **L** — источники света |
| `ds2md_view` | ЛКМ — вращение; **Shift+ЛКМ** — свет; ПКМ/СКМ — панорама; колесо — масштаб; **F** — вместить модель; **W** — каркас; **G** — сетка; **L** — сбросить свет; **Space** — воспроизведение/пауза; **[** / **]** — клипы; **B** — исходная геометрия; стрелки — переход по времени; **R** — повтор; **Ctrl+Shift+E** — экспорт GLB |

## Python-инструменты

Команды запускаются из корня репозитория. При передаче каталога поиск файлов выполняется рекурсивно.

Проверить карты и получить сводку JSON:

```powershell
python -m ds2_research.inspect_ds2 'path/to/gameres/maps'
```

Добавить записи мешей и смещения массивов к отчёту одной карты:

```powershell
python -m ds2_research.inspect_ds2 'path/to/map.ds2' --meshes
```

Проверить модели и получить JSON-отчёт:

```powershell
python -m ds2_research.inspect_ds2md 'path/to/gameres/models'
```

Для одного файла выводятся декодированные метаданные и смещения. Геометрия и массивы матричных отсчётов в отчёт не разворачиваются. При ошибках разбора каталога программа возвращает ненулевой код завершения.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

Тесты используют синтетические данные и не требуют файлов игры или графического контекста.

## Упаковка исходников viewer

```powershell
python tools/package_viewer.py
```

Создаётся `dist/ds2-viewers-source.zip`. Архив содержит только CMake/PowerShell-файлы и C++-исходники с шейдерами; ресурсы игры, Qt и собранные программы в него не попадают. Другой путь задаётся через `--output`.

## Структура репозитория

```text
.
├── ds2_research/       # Python-парсеры, материалы, сцены и анимация
├── docs/               # Исследования DS2, DS2MD и vistree
├── formats/            # Шаблоны для редакторов бинарных файлов
├── tests/              # Автономные регрессионные тесты Python
├── tools/              # Вспомогательные утилиты репозитория
├── viewer/             # C++20/Qt 6 viewer, QRhi и шейдеры
├── build.ps1           # Настройка и сборка через CMake/Ninja
├── install.ps1         # Установка viewer и Qt runtime
└── CMakeLists.txt      # Цели ds2_view, ds2md_view и viewer_common
```

`build/`, `install/`, `dist/`, кэши Python и виртуальные окружения исключены из Git.
